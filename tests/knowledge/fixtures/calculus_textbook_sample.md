# 第一章 函数与极限

## 第一节 函数

函数是微积分的研究对象。设数集 D 包含于实数集，若存在对应法则 f，对 D 中每个数 x，都有唯一确定的实数 y 与之对应，则称 f 为定义在 D 上的函数，记作 y = f(x)。

## 第二节 函数的极限

### 函数极限的概念

设函数 f(x) 在点 x0 的某去心邻域内有定义。如果当 x 趋于 x0 时，函数值 f(x) 无限接近于某个常数 A，则称 A 为函数 f(x) 当 x 趋于 x0 时的极限，记作 lim_{x→x0} f(x) = A。类似地可以定义 x 趋于无穷时的函数极限。

### 函数极限的定义

函数极限的严格定义（ε-δ 语言）：对任意给定的正数 ε，总存在正数 δ，使得当 0 < |x - x0| < δ 时，恒有 |f(x) - A| < ε，则称 A 是 f(x) 当 x→x0 时的极限。

## 第三节 极限运算法则

### 极限的四则运算法则

若 lim f(x) = A，lim g(x) = B，则在极限存在的前提下，有：lim [f(x) ± g(x)] = A ± B；lim [f(x) · g(x)] = A · B；当 B ≠ 0 时，lim [f(x) / g(x)] = A / B。这些极限运算法则是将复杂极限拆解为基本极限的基础工具。

### 极限运算法则的应用

利用极限运算法则，可以先分别求出各部分的极限，再按四则运算组合。需注意只有在各部分极限都存在时才能直接套用极限运算法则，否则应先做代数变形（如约分、通分、有理化）。

## 第四节 两个重要极限

第一个重要极限是 lim_{x→0} sin x / x = 1；第二个重要极限是 lim_{x→∞} (1 + 1/x)^x = e。它们是计算三角函数与指数函数极限的重要工具。

# 第二章 导数与微分

## 第一节 导数的概念

### 导数的定义

设函数 y = f(x) 在点 x0 的某邻域内有定义，当自变量在 x0 处取得增量 Δx 时，函数增量 Δy = f(x0 + Δx) - f(x0)。若极限 lim_{Δx→0} Δy/Δx 存在，则称该极限为 f(x) 在 x0 处的导数，记作 f'(x0)，即 f'(x0) = lim_{Δx→0} [f(x0+Δx) - f(x0)] / Δx。导数刻画了函数在该点处的变化率。

### 导数的几何意义

函数 y = f(x) 在点 x0 处的导数 f'(x0) 在几何上表示曲线 y = f(x) 在点 (x0, f(x0)) 处切线的斜率。因此切线方程为 y - f(x0) = f'(x0)(x - x0)。

## 第二节 导数的计算

### 基本求导公式

常见基本初等函数的求导公式包括：(x^n)' = n x^{n-1}；(sin x)' = cos x；(cos x)' = -sin x；(e^x)' = e^x；(ln x)' = 1/x 等。这些是求导计算的基础。

### 复合函数求导

复合函数求导使用链式法则：若 y = f(u)，u = g(x)，则 dy/dx = (dy/du) · (du/dx)。进行求导计算时应由外层向内层逐层求导并相乘。

### 高阶导数

对函数求导所得的导函数再求导，称为二阶导数，记作 f''(x) 或 d²y/dx²。类似地可以定义三阶及更高阶的导数。高阶导数在研究函数的弯曲形态时非常重要。二阶导数是判断函数凹凸性的核心工具。

# 第三章 微分中值定理与导数的应用

## 第一节 中值定理

微分中值定理（拉格朗日中值定理）指出：若函数在闭区间连续、开区间可导，则存在一点 ξ 使 f'(ξ) = [f(b) - f(a)] / (b - a)。中值定理是连接导数与函数整体性质的重要桥梁。

## 第二节 函数的单调性与极值

### 单调性的判定

利用一阶导数可以判定函数的单调性：若在区间上 f'(x) > 0，则函数单调递增；若 f'(x) < 0，则函数单调递减。求出一阶导数并分析其符号区间，即可得到函数的单调区间。

### 极值的求法

令 f'(x) = 0 得到驻点，再结合一阶导数符号变化或二阶导数，可以判断驻点是否为极值点以及是极大值还是极小值。

## 第三节 函数的凹凸性与拐点

### 函数的凹凸性

设函数 f(x) 在区间 I 上连续。若对 I 上任意两点 x1, x2，恒有 f((x1+x2)/2) < [f(x1)+f(x2)]/2，则称曲线在区间 I 上是凹的（下凸）；若不等号反向，则称为凸的（上凸）。函数的凹凸性描述了曲线的弯曲方向。

### 凹凸区间

使函数保持凹（或凸）的连续区间称为凹凸区间。求凹凸区间的关键是分析二阶导数的符号：二阶导数大于零对应凹区间，二阶导数小于零对应凸区间。把定义域按二阶导数为零或不存在的点划分，即可逐段确定凹凸区间。

### 拐点

连续曲线上凹弧与凸弧的分界点称为拐点。拐点对应二阶导数变号的点，通常出现在 f''(x) = 0 或二阶导数不存在的点处。求拐点时应验证该点两侧二阶导数是否确实变号。

### 二阶导数判定法

二阶导数判定法是判断函数凹凸性与拐点的标准方法：计算 f''(x)，令 f''(x) = 0 找出候选点；在候选点两侧若 f''(x) 由正变负或由负变正，则该点为拐点，且曲线在该点两侧分别为凸、凹或凹、凸。求函数的凹凸区间并判断拐点，本质上就是先求一阶导数、再求二阶导数，然后分析二阶导数的符号区间。

#### 用二阶导数判断凹凸性

具体步骤：第一步求一阶导数 f'(x)；第二步求二阶导数 f''(x)；第三步解方程 f''(x) = 0；第四步列表讨论各区间上 f''(x) 的符号，从而写出凹凸区间并标出拐点。整个过程以二阶导数判定法为核心，一阶导数主要用于求出二阶导数的前置计算。
