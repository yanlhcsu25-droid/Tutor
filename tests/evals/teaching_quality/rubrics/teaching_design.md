# Teaching Design rubric v1

Score each axis 1–5 using output evidence only: **5** fully meets the requirement with clear teaching value; **4** correct with minor non-blocking weakness; **3** usable with a material weakness; **2** partly meets the need but is poor; **1** seriously wrong or unusable.

- **scope_fidelity** — 5 stays entirely in the requested curriculum and learner stage; 3 has harmless edge material; 1 clearly exceeds scope.
- **objective_alignment** — 5 every activity serves the stated goal; 3 contains generic detours; 1 is disconnected.
- **learning_progression** — 5 uses a coherent diagnosis → foundation → method → integration → check sequence when appropriate; 3 has an understandable but weak sequence; 1 is disordered.
- **feasibility** — 5 fits time, workload, and learner level; 3 needs modest trimming; 1 is not executable.
- **assessment_alignment** — 5 checks the taught objective directly; 3 checks it incompletely; 1 teaches and assesses different things.

Judge soft quality only. Counts, duration arithmetic, required sections, and forbidden content belong to structural assertions.
