# 数据集审计

审计日期：2026-07-23。原始数据保存在 `data/external/`，该目录已被
Git 忽略，不随项目仓库分发。

## 结论

CMM-Math 是当前中文初中组卷的主数据源。MM-Math 保留为英文多模态
评测入口，不再被描述成中文题库。

## CMM-Math

- 官方地址：<https://huggingface.co/datasets/ecnu-icalk/cmm-math>
- 许可证：BSD 3-Clause（以官方数据集卡为准）
- 全量记录：28,069
- 字段：`id`、`image`、`answer`、`solution`、`level`、`question`、
  `options`、`subject`、`analysis`
- 初中记录：6,335
  - 七年级：2,209
  - 八年级：1,733
  - 九年级：2,393
- 初中带图片记录：3,352
- 初中缺少答案：37
- 初中缺少解析：692

首版采用以下保守过滤条件：

1. 只保留七、八、九年级；
2. 排除 `image` 非空或正文包含 `<ImageHere>` 的题；
3. 要求答案和解析同时存在；
4. 暂不推断难度；
5. 将 `subject` 作为待细化的粗粒度知识标签。

按此规则实际导入 2,716 题：

| 年级 | 选择题 | 填空题 | 解答题 | 合计 |
|---|---:|---:|---:|---:|
| 七年级 | 730 | 249 | 499 | 1,478 |
| 八年级 | 220 | 71 | 246 | 537 |
| 九年级 | 411 | 141 | 149 | 701 |
| 合计 | 1,361 | 461 | 894 | 2,716 |

题型是根据 `options`、答案形式和题干占位符确定性推断的，仍需抽样评估
准确率。数据本身没有可直接用于组卷的难度字段，`subject` 也只是“代数”
“解析几何”等粗分类，因此下一阶段必须由知识分类 Agent 检索教材目录并
产生候选标签，再通过抽样复核建立评测集。

## MM-Math

- 官方地址：<https://huggingface.co/datasets/THU-KEG/MM_Math>
- 许可证：MIT（以官方数据集卡为准）
- 实际 JSONL 记录：5,901
- 题干含中文：1
- 年级编码：`seven`、`eight`、`nine`
- 难度编码：`easy`、`medium`、`hard`
- `knowledge` 是包含 `level_1`、`level_2` 的对象
- 5,491 题疑似依赖图片
- 全部按开放题提供，不能支撑选择题、填空题配额

原适配器曾错误假设它是中文数据，并把 `knowledge` 当作数组。现已修正
语言、年级、难度、知识层级、`file_name` 和 `\boxed{}` 答案提取。

## 已验证场景

在隔离的内存数据库中全量扫描 CMM-Math，并用上述规则导入后，以下蓝图
成功生成且所有硬约束满足：

- 八年级；
- 10 题、100 分；
- 至少 4 道选择题、2 道填空题；
- 固定随机种子 42。

这只证明数据导入和确定性题型约束闭环可运行，不代表知识点标注和难度控制
已经完成。
